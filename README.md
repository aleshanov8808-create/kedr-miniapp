# Kedr Mini App

Мини-приложение Telegram для демо-бота гостевого дома «Кедр» ([@kedr_demo_booking_bot](https://t.me/kedr_demo_booking_bot)).
Гость выбирает домик, даты (занятые ночи недоступны), число гостей и допуслуги, вводит имя и телефон и видит итоговую цену. Кнопка «Отправить заявку» передаёт заявку боту, а бот отправляет её хозяину.

Это обычная статическая страница (HTML/CSS/JS), сборка не нужна. Папка `screens/` — только скриншоты, на работу приложения она не влияет.

## Как включить GitHub Pages
1. Загрузите файлы в репозиторий `kedr-miniapp` (в корень ветки `main`).
2. В репозитории откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`, и нажмите **Save**.
4. Через 1–2 минуты страница откроется по адресу https://aleshanov8808-create.github.io/kedr-miniapp/

## Подключение к боту
В файл `.env` бота добавьте строку:

```
WEBAPP_URL=https://aleshanov8808-create.github.io/kedr-miniapp/
```

После этого перезапустите бота. В чате появится кнопка «✨ Открыть приложение». Бот сам передаёт занятые даты в параметре `?b=`.

## Если меняются цены или домики
Цены, домики и услуги заданы в начале `app.js` и должны совпадать с `content.py` бота. Правила (`MAX_NIGHTS`, `BOOK_AHEAD_DAYS`, `PHONE_RE`) должны совпадать с `bot.py`.
